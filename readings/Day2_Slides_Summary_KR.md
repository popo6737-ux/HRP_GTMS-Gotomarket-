## 2. 가장 중요한 실무 포인트 — TAM 계산에 대한 LinkedIn 투자자 경고 (슬라이드 3)

VC(Itamar Novick)가 "최악의 피치" 시리즈에서 지적: **"우리 TAM은 1,000억 달러다, 모두가 소프트웨어를 쓰니까"** 식의 계산은 실제로 이 문제를 가진 고객이 몇 명인지, 지금 얼마를 내고 있는지, 3년 내 도달 가능한 고객 수를 전혀 말해주지 못함. 반대로 잘한 예: **"북미 중견 제조기업 2,500개 중 400개가 QC 소프트웨어에 평균 5만 달러를 쓰고, 우리는 초기 타깃 60개를 식별했다 — 그게 우리의 bottom-up TAM이다."**
→ **"Top-down TAM은 구글링했다는 걸 보여주고, Bottom-up TAM은 고객을 이해하고 있다는 걸 보여준다."** 이건 지난 pre-assignment(엔도톡신/FoamFit)에서 이미 다룬 논리와 정확히 같으며, Task 1에서도 그대로 적용해야 함.

## 3. Part 1 — 고객 세그멘테이션: 3단 계층 구조

**타깃 고객(시장 세그먼트) → ICP(기업/조직 수준) → 바이어 페르소나(개인)** — B2B에서는 ICP 1개당 페르소나 여러 개가 붙음(DMU 때문).

**DMU 5역할**: 경제적 구매자(예산 승인, CFO/VP) / 기술적 구매자(스펙 검증, IT Director/CTO) / 실사용자(매일 사용, Sales Rep) / 챔피언(내부 옹호자) / 차단자(변화 저항). 같은 페르소나가 여러 역할(예: 실사용자+챔피언)을 겸할 수 있음.

**가치제안 = 문제 + 효익 + 차별화** 3요소. 흔한 실수 6가지: 너무 모호함 / 모두를 타깃 / 경쟁사 무시 / 기능만 나열(효익 없음) / 약한 차별화("더 나은 서비스") / 증거 없는 주장("10배 빠름"). Slack·Stripe 사례로 이 3요소가 어떻게 실제 문장이 되는지 보여줌: *"~로 시간을 잃는 팀을 위해(문제), ~하는 협업허브입니다(효익), 왜냐하면 ~하기 때문입니다(차별화)."*

**같은 제품·같은 포지셔닝이라도 DMU 역할마다 메시지는 달라져야 함** (Slack 예시: 실사용자엔 "타이핑 그만, 클로징 시작", 챔피언엔 "실제 파이프라인을 보세요", 경제적구매자엔 "35% 더 많은 판매시간").

**흥미로운 캠페인 사례 6개(De Beers 다이아몬드, 리스테린 halitosis, 펩소던트 양치습관, 담배업계 Frank Statement, "아침은 가장 중요한 식사", 럭키스트라이크 여성흡연)** — 공통 패턴: 문제가 없던 곳에 "문제를 발명"하거나, 시장 자체가 없던 곳에 "습관을 발명"함. 마케팅의 힘과 윤리적 위험을 동시에 보여주는 사례들.

## 4. Part 2 — 수익모델과 가격

**비즈니스 모델("무엇을,누구에게") vs 수익모델("어떻게")** 구분이 핵심. 비즈니스모델 6유형(B2B/B2C, 마켓플레이스, SaaS, 플랫폼/생태계, D2C, 하드웨어+소프트웨어)과 수익모델 7유형(구독, 프리미엄, 광고, 사용량기반, 일회성구매, 제휴, 거래수수료, 데이터수익화, 엔터프라이즈 맞춤가격)은 서로 다른 축 — 하나의 비즈니스모델이 여러 수익모델을 조합할 수 있음(Duolingo: 프리미엄+광고+구독으로 이용자 세그먼트별 수익화).

**가격전략 6가지**: 경쟁가격(기존시장) / 침투가격(빠른 도입 필요한 신규진입자) / 티어드가격(다양한 세그먼트의 SaaS) / **가치기반가격**(ROI가 명확할 때 — "10만불 절약해주면 1만불 청구 정당화") / 원가가산(실물제품) / 동적가격(여행·이벤트 등 한정재고).

## 5. Part 3 — Product-Market Fit

**PMF 없음 = #1 스타트업 킬러** (자금 소진보다 더 근본적 원인). PMF 전/후 대비표로 명확히 구분.

**Sean Ellis Test**(핵심 도구): "이 제품을 더 이상 못 쓴다면?" 질문에 **"매우 실망" 응답이 40% 이상**이면 PMF 달성. (Day 1 자료에서 이미 다룬 Superhuman 사례가 이 프레임워크의 실전 적용임 — 22%→58%로 끌어올린 그 방법론.)

**PMF 피라미드(Dan Olsen, 2015)**: 아래부터 타깃고객→미충족니즈 (**PMF 라인**) →가치제안→기능세트→UX. 기초(타깃고객·니즈)가 흔들리면 위(가치제안·기능·UX)는 절대 버티지 못함 — **PMF 라인을 넘기 전에 반드시 기초부터 확실히 할 것.**

**PMF 신호**: 고객이 끌어당김(inbound>outbound) / 유기적 입소문 / 높은 유지율 / Sean Ellis 40%+. **PMF 없다는 신호**: 긴 세일즈사이클 / 초기구매후 높은 이탈 / "흥미롭다"는 정중한 반응(수요 아님) / 지출해야만 성장.

**흔한 실수 4가지**: PMF 전 확장(채용·광고·투자유치를 먼저) / 초기 견인력(친구 가입, PR 스파이크)을 PMF로 착각 / 모두를 위해 만들어 제품 희석 / 이탈 무시. Airbnb 사례: 명확한 타깃고객→미충족니즈(신뢰) 식별→가치제안 정교화(전문사진·리뷰·안전결제)→UX가 신뢰 강화→예약 증가로 PMF 확인.

## 6. Part 4 — 마케팅과 고객 여정

**여정 모델의 120년 진화**: 선형퍼널(AIDA, 1908) → McKinsey 고객의사결정여정(순환형, 2009) → 고객경험여정(구매전/구매/구매후 전체, Lemon&Verhoef 2016) → 생태계기반여정(플랫폼·소셜증거가 만드는 것). 핵심: **"퍼널이 아니라 여러 경로가 있는 여정"** — 고객은 어느 지점에서든 진입·이탈·되돌아감 가능. 구매 후 경험이 **충성 루프**를 만들어 재평가 없이 재구매하게 함.

**B2B 구매가 어떻게 변했나**: **70%의 B2B 의사결정자가 영업사원 상담 없이 구매할 의향**(SalesIntel 2024) — Day 1의 HBR·Gartner 자료(17%, 43%, 67%)와 같은 흐름의 최신 수치. 구매자는 초정보화되어 있고, 자기주도적으로 여정 대부분을 진행하며, 세일즈와 접촉할 땐 이미 전문성을 기대함.

**시사점 5가지**: 셀프서비스 리서치 가능하게(콘텐츠가 몇 달간 유일한 "영업사원") / 구매후 경험 중시(재획득보다 충성루프가 효율적) / 모든 단계에 맞는 콘텐츠 / 퍼널 전 과정에 존재 / 디지털 존재감은 협상불가.

**B2B vs B2C 비교표**: B2B는 다수 의사결정자(DMU), 긴 사이클, 이성적/ROI중심, 고액거래, 마케팅+세일즈 핸드오프모델. **마케팅-세일즈 SLA**: 마케팅은 "월 X개 MQL 전달" 약속, 세일즈는 "Y시간 내 팔로업+피드백" 약속 — MQL/SQL 정의에 합의하고 지표를 공유해야 함. **MQL→SQL→Lead→Contact→Meeting→Proposal→Win** 파이프라인으로 연결됨.

## 7. Part 5 — 마케팅 채널

**5대 카테고리**: 디지털(소셜·검색·이메일·콘텐츠·비디오) / 유료광고 / 자체채널(웹사이트) / 파트너십 / 직접채널(이벤트, 세일즈와 겹침) / 획득미디어(살 수 없고 얻을 수만 있음).

**채널 선택 4기준**: 오디언스 적합성(페르소나가 어디 있나) / 고객여정 단계(인지 vs 전환) / 예산·자원 / 측정가능성.

**여정단계별 콘텐츠 매칭**: Awareness("문제가 있다"→블로그·인포그래픽) / Consideration("옵션이 뭔가"→백서·웨비나·비교가이드) / Decision("왜 이거"→데모·무료체험·ROI계산기·추천사).

**핵심 지표 4개(다음 모듈 예고)**: CAC(고객획득비용), CPL(리드당비용), ROAS(광고지출대비수익), LTV:CAC(생애가치 비율).

## 8. Part 6 — 콘텐츠에서 캠페인으로

**캠페인 vs 상시마케팅(Always-On)**: 캠페인은 정해진 시작/종료+구체적목표, 상시는 지속적+넓은목표(SEO·주간블로그) — 대부분 프로그램은 둘을 결합.

**캠페인 6유형**: 브랜드인지도(도달·노출) / 리드생성(CPL) / 제품런칭(가입·초기매출) / 육성캠페인(MQL) / **ABM**(고가치 계정 개인화 타겟팅, 계정참여도) / 이벤트/시즌(등록·참석률).

**캠페인 해부 7요소**: 목표(SMART) → 오디언스 → 메시지 → 채널 → 콘텐츠 → CTA → 측정.

**리드생성 실무**: 게이트 콘텐츠(폼 필요, 리드 확보 but 도달 감소) vs 비게이트(자유접근, SEO+신뢰 but 직접 리드확보 없음) — **최근 트렌드는 대부분 비게이트화, 고가치 자산·데모요청만 게이트**. 리드캡처 프로세스: 트래픽→랜딩페이지→폼→감사페이지→CRM리드. 폼은 "필드 많을수록 마찰 많고 리드 줄어듦"이 핵심 원칙.

**캠페인 계획 템플릿(10항목)**: 이름/목표(SMART)/오디언스/핵심메시지/오퍼·CTA/채널/콘텐츠자산/타임라인/예산/KPI — **Task 2에서 이 구조를 그대로 활용**.

## 9. Part 7 — 마케팅 측정

**지표 4계층(활동→참여→전환→비즈니스)**: 활동(발송/게시 수)이 참여(오픈/클릭)를 이끌고 → 참여가 전환(리드/MQL)을 이끌고 → 전환이 비즈니스 성과(매출/ROI)를 이끔. **모든 계층을 추적하되, 비즈니스 임팩트에 맞춰 최적화.**

**핵심 KPI 9개**: CAC, LTV, **LTV:CAC(목표 3:1 이상, 1:1 미만은 손실)**, CPL, ROAS, 마케팅ROI, MQL→SQL비율, 파이프라인기여도, 회수기간(Payback Period).

**마케팅 ROI 공식**: (마케팅 기인 매출 - 마케팅 비용)/마케팅 비용×100. 예시: 매출 8만유로, 비용 2만유로 → **ROI 300%**.

**A/B 테스트 4단계**: 가설→테스트(동시실행)→측정→학습. 한 번에 변수 하나만.

**경영진 리포팅 주기**: 주간(활동지표·캠페인성과) / 월간(파이프라인·채널성과·MQL목표대비) / 분기(ROI분석·전략리뷰·예산권고).
