→ **이 산출물이 최종 발표(Final Presentation)의 Snapshot 슬라이드에 그대로 들어감.** 즉, pre-assignment에서 만든 Bottom-up 논리를 그대로 확장해서 이번 Task 1의 4단계에 맞게 다시 정리해두면 재활용 가능.

## 4. AI 사용 정책 — 이번 수업 한정 도구 지급

- **"Claude Sonnet 5 + Perplexity"** 통합 툴을 강사가 직접 제공 (Canvas 링크, 비밀번호 `GTM4you`).
- 규칙: **공개 데이터만 입력할 것** (회사 기밀/개인정보 입력 금지).
- **AI 사용 고지문을 과제마다 명시적으로 작성해야 함** — 슬라이드 18에 강사 본인의 실제 문구 예시가 제공됨: *"이 자료 준비 중 Claude를 콘텐츠 구조화에 활용했고, 생성된 내용을 검토·수정했으며 전적인 책임을 진다."* → 이 문구 톤을 그대로 본인 과제의 AI Use Disclosure에 적용하면 됨(이미 동주님 과제 커버페이지에 유사한 문구가 있음 — 일치함).
- **"Doomprompting" 경고**: Anu Atluru의 에세이를 인용해, AI와의 대화가 생산적으로 "느껴지지만" 실제로는 수동적 소비가 될 수 있다고 경고. AI는 브레인스토밍·피드백에는 강하지만 **진짜 사고가 필요한 창의적 핵심 작업은 대신해줄 수 없다**는 게 핵심 메시지. → 과제/발표 준비 시 AI로 초안을 만들되, 논리의 핵심 판단(왜 이 시장인지, 왜 이 방법인지)은 반드시 본인이 검증해야 한다는 이번 학기 전체의 원칙과 일치.

## 5. GTM 프레임워크 (이 수업이 쓰는 정의)

**Before**(아이디어 검증) → **Foundation**(시장조사·타깃고객·경쟁분석·가치제안·가격전략) → **Execution**(세일즈전략·마케팅전략·고객지원) → **Monitoring**(성과지표·피드백 루프) → **After**(장기 스케일링) — 이 전체가 **선형이 아니라 순환·반복 구조**임을 강조 ("목표 달성까지 계속되는 진행형 프로세스").

## 6. 가장 인상적인 데이터 포인트 — Startup Handbook 인용

강사가 직접 **"Startup Handbook"(Timo Ahopelto & Jyri Engeström, 2025)**을 인용하며, 101개 스타트업 사후분석 결과 스타트업 실패 원인 상위 10개를 제시:

1. 시장 니즈 부재 — **42%** (압도적 1위)
2. 자금 소진 — 29%
3. 잘못된 팀 — 23%
4. 경쟁사 시장 장악 — 19%
5. 가격/비용 문제 — 18%
6. 부실한 제품 — 17%
7. 비즈니스 모델 실패 — 17%
8. 약한 마케팅 — 14%
9. 고객 무시 — 14%
10. 잘못된 타이밍 — 13%

강사의 질문 프레이밍("이 중 몇 개가 시장 조사와 관련 있는가?")이 핵심 — **10개 중 다수(시장 니즈 부재, 경쟁사 장악, 가격 문제, 비즈니스 모델 실패, 고객 무시 등)가 결국 "시장/고객을 제대로 조사하지 않음"으로 수렴**한다는 것을 스스로 깨닫게 하려는 의도로 보임. 이는 정확히 이 모듈이 Day 1을 시장 사이징+경쟁분석+ICP로 시작하는 이유이자, pre-assignment에서 다룬 "Bottom-up으로 고객을 직접 세라"는 원칙과도 일맥상통.

## 7. Part 2~5 요약 (슬라이드 19~73)

### GTM 개론 & Juicero 케이스 (19~28)
- GTM 정의: "제품 출시·신시장 진입 시 타깃 고객에게 도달하고 경쟁우위를 확보하는 방법을 담은 종합 실행계획". 이 수업은 **초기단계 B2B + 시장/고객 조사**에 방점.
- **Juicero 케이스**(1.2억 달러 투자, 초기가 $699 WiFi 착즙기, 결국 실패): 실패 원인 3가지 — ① 시장 니즈 검증 부족(프리미엄을 낼 거라 가정만 함) ② 타깃 고객 오판(니치 시장 규모 과대평가) ③ 경쟁 구도 무시("세계 최초"라 홍보했지만 실은 유사 제품 다수 존재). 결론: **"아무도 갖지 않은 문제에 대한 비싼 해결책"**.
- 이 실패가 슬라이드 21의 GTM 프레임워크 표와 다시 연결됨 — Foundation(시장조사/타깃고객/경쟁분석/가치제안/가격전략) 단계가 부실하면 Monitoring의 피드백 루프가 결국 "기초로 돌아가라"는 신호를 보낸다는 걸 시각적으로 강조.

### TAM/SAM/SOM 정의와 계산법 (29~50) — **Task 1에 바로 쓸 핵심 내용**
- **TAM**: 100% 점유율 가정 시 총 매출 기회. **SAM**: 오퍼링·비즈니스모델·시장접근성 제약을 반영한 TAM의 일부. **SOM**: 3~5년 내 실제로 확보 가능한 SAM의 비중(경쟁사 존재 감안).
- **Uber TAM 사례**(가장 중요한 케이스): 2014년 Damodaran 교수는 "택시 시장 TAM($100B)"을 기준으로 Uber 가치를 최대 $6~12B로 추정 → 틀림. Bill Gurley의 반박: "기존 시장 규모로 파괴적 혁신기업을 사이징하는 건, 미래가 과거와 같다고 가정하는 것" — Uber는 픽업시간 단축·결제 편의·평점 신뢰 등으로 **시장 자체를 확장**시켰고, 실제로는 "택시"가 아닌 "라이드헤일링"이라는 새 시장에서 경쟁. 여기에 UberEats(매출 30%+)까지 더해져 2025년 시가총액 $196B. → **결론: 기존 산업의 TAM으로 파괴적 신사업을 재단하지 말 것.** (Aaron Levie 인용: "1910년의 말(馬) 숫자로 자동차 산업 규모를 재는 것과 같다")
- **계산법 3가지**:
  - **Top-down**: 큰 산업 리포트(Gartner 등) → 비율 적용해 좁힘. 장점: 빠름/기존 리서치 활용. 단점: 데이터 의존/사업과 괴리감. 예시: 퍼블릭클라우드 $723.4B → 클라우드보안 10%=$72B → 중견기업 25%=$18B → 북미 40%=$7.2B
  - **Value theory**: 비교 제품 가격 + 자사 우위가 정당화하는 프리미엄. 신제품·출시 전 사업에 유용.
  - **Bottom-up**: 잠재고객 수 × ACV(연간계약금액). 예시: 법률사무소 회계플랫폼, ACV 2,400유로 × 유럽 100만 곳 = TAM 24억 유로 → 북유럽 5만 곳(SAM) = 1.2억 유로 → 실제 파이프라인 1,500곳(SOM) = 360만 유로
  - **Triangulation**: 두 방법을 결합해 범위(range)로 제시 — "우리 SAM은 5천만~1억 유로" 식. 컨설팅/기업전략에서는 한 방법만 쓰면 불완전해 보일 수 있음.
- **흔한 실수 2가지**: ① "모두가 고객"(TAM=스마트폰 이용자 40억명 같은 정의) — 구체적 세그먼트로 좁혀야 함. ② "1년차에 25% 점유" — 실제로는 신규진입자 1~5%, 인접시장 진출 기존업체 5~15%, 핵심시장 리더 20~40%가 현실적 범위. 과대추정은 투자자 신뢰 상실+잘못된 의사결정+훌륭한 실행조차 "실패"로 보이게 만듦.
- **시장 환경 변수**: COVID→재택근무(Zoom 1000만→3억 이용자), GDPR→데이터브로커 산업 소멸 — 외부 요인이 하룻밤 새 시장을 만들거나 없앨 수 있음.
- **좋은 프롬프트 5요소**: 페르소나/목표/청중/맥락/경계 — Task 1에서 AI로 잠재고객 수를 조사할 때 이 구조로 프롬프트를 짜면 효과적.
- **Warm-up 그룹과제**: 폴란드 주택용 태양광 설치회사의 TAM/SAM/SOM 계산 (주택소유율·전기요금·정부인센티브·경쟁사 조사 → 1슬라이드로 발표·방어).

### PESTEL 프레임워크 (54~62)
거시환경 6개 렌즈 — **P**정치(정책/관세/세제) · **E**경제(GDP/금리/환율) · **S**사회(인구통계/트렌드) · **T**기술(신기술/자동화) · **E**환경(기후/지속가능성) · **L**법률(규제/데이터보호). 각 요인마다 "핵심 질문" + 기회/위협 예시 제공. EV 충전 스타트업 전체 PESTEL 예시로 마무리 (P:그린딜자금 / E:고금리 vs 유가상승 / T:급속충전기술 / S:기후의식 / E:탄소배출권 / L:AFIR규제).

### Porter's Five Forces (63~73)
경쟁분석 4단계: **식별**(직접/간접/잠재 경쟁자, 밀키트 예시) → **포지션**(2축 포지셔닝맵, PM소프트웨어 예시 Trello/Notion/Monday/Asana/Jira) → **분석**(5 Forces) → **수집**(공개정보+제3자소스+고객인터뷰로 지속적 모니터링).
5가지 힘 각각 "핵심 질문 + 높은/낮은 경우 조건 + 실제 사례"로 구성:
- **신규진입 위협**: 낮은 자본요구·약한 브랜드충성도면 위협 높음 (음식배달 vs 항공업)
- **공급자 협상력**: 소수 공급자·높은 전환비용이면 힘 셈 (TSMC vs 사무용품)
- **구매자 협상력**: 소수 대형구매자·낮은 전환비용이면 힘 셈 (Walmart vs 럭셔리브랜드)
- **대체재 위협**: 더 나은 가성비·낮은 전환비용이면 위협 높음 (화상회의 vs 시멘트)
- **산업 내 경쟁**: 비슷한 규모 다수·느린 성장이면 경쟁 치열 (항공업 vs 명품시계)
